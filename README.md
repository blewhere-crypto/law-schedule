# 변호사 일정관리 페이지

재판기일, 서면 제출 마감 등 업무 일정을 관리하는 1인용 웹 대시보드입니다.
상단에는 임박한 순서로 "중요 일정"을 보여주고, 하단에는 월간 캘린더로 전체 일정을 볼 수 있습니다.

- 별도 서버/데이터베이스 없이 **브라우저 로컬 저장소(localStorage)**에만 데이터를 저장합니다.
  → 사건 정보가 외부로 전송되지 않고, 오직 이 브라우저(이 기기)에만 남습니다.
  → 단점: 다른 브라우저나 다른 기기에서 열면 일정이 보이지 않습니다. (기기 간 동기화가 필요하면 다음 단계에서 클라우드 DB 연동을 추가할 수 있습니다.)

## 로컬에서 바로 사용하기

`index.html` 파일을 더블클릭해서 열면 바로 사용할 수 있습니다. (별도 설치/서버 불필요)

## 웹페이지로 배포하기 (GitHub Pages, 무료)

1. 이 폴더로 새 GitHub 저장소를 만들고 push 합니다.
   ```bash
   cd law-schedule
   git init
   git add index.html README.md
   git commit -m "일정관리 페이지 초안"
   git branch -M main
   git remote add origin <본인의 GitHub 저장소 주소>
   git push -u origin main
   ```
2. GitHub 저장소 **Settings → Pages**에서 Source를 `main` 브랜치 `/ (root)`로 설정합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.
4. 이 주소를 즐겨찾기 해두고 사용하면 됩니다. (매번 같은 브라우저로 접속해야 저장된 일정이 유지됩니다)

> 저장소를 **비공개(private)**로 만들어도 GitHub Pages(유료 플랜 필요) 또는 Netlify/Vercel 같은 다른 무료 정적 호스팅 서비스를 대신 써도 됩니다. 데이터 자체는 브라우저에만 저장되므로 호스팅 서비스에는 사건 내용이 전달되지 않습니다.

## 사용법

- 우측 상단 **"+ 일정 추가"** 버튼으로 일정을 등록합니다. (사건명, 일정유형, 날짜, 시간, 법원, 메모)
- 일정유형은 자유 입력이며 변론기일/선고기일/준비기일/조정기일/서면제출 등을 추천 목록으로 제공합니다.
- 상단 "중요 일정" 목록은 완료되지 않은 일정을 날짜순으로 보여주며, 기한이 지난 항목은 빨간색, 3일 이내 항목은 주황색으로 강조됩니다.
- 각 일정의 체크박스를 누르면 "완료" 처리되어 상단 목록에서 빠집니다. (완료 항목은 "완료된 일정도 보기" 체크로 다시 볼 수 있습니다)
- 캘린더에서 날짜를 클릭하면 해당 날짜의 일정 목록/추가 화면이 열립니다.
