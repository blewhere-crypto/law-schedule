# 변호사 일정관리 페이지

재판기일, 서면 제출 마감 등 업무 일정을 관리하는 1인용 웹 대시보드입니다.
상단에는 임박한 순서로 "중요 일정"을 보여주고, 하단에는 캘린더 또는 사건별(의뢰인)로 전체 일정을 볼 수 있습니다.

**배포 주소: https://blewhere-crypto.github.io/law-schedule/**

- 별도 서버/데이터베이스 없이 **브라우저 로컬 저장소(localStorage)**에만 데이터를 저장합니다.
  → 사건 정보가 외부로 전송되지 않고, 오직 이 브라우저(이 기기)에만 남습니다.
  → 단점: 다른 브라우저나 다른 기기에서 열면 일정이 보이지 않습니다. (기기 간 동기화가 필요하면 다음 단계에서 클라우드 DB 연동을 추가할 수 있습니다.)
- PWA(홈 화면 앱)로 설치할 수 있어 모바일에서 앱처럼 사용할 수 있습니다.

## 모바일에서 앱처럼 설치하기

1. 휴대폰 브라우저에서 위 배포 주소로 접속합니다.
2. **iPhone(Safari)**: 공유 버튼 → "홈 화면에 추가"
   **Android(Chrome)**: 우측 상단 메뉴(⋮) → "홈 화면에 추가" / "앱 설치"
3. 홈 화면에 생긴 아이콘을 누르면 주소창 없이 앱처럼 열립니다. 서비스워커가 파일을 캐시해두기 때문에 오프라인에서도 마지막으로 열어본 화면은 그대로 볼 수 있습니다(단, 새 일정 저장은 이 기기 브라우저에만 남습니다).

## 로컬에서 바로 사용하기

`index.html` 파일을 더블클릭해서 열면 바로 사용할 수 있습니다. (별도 설치/서버 불필요)

## 웹페이지로 재배포하기 (GitHub Pages)

이미 `blewhere-crypto/law-schedule` 저장소로 배포되어 있습니다. 코드를 수정한 뒤에는 커밋하고 push만 하면
GitHub Pages가 몇십 초 안에 자동으로 새 버전을 반영합니다.

```bash
git add -A
git commit -m "변경 내용"
git push
```

> 저장소는 공개(public)입니다. 코드(화면 UI)만 공개되고, 실제 일정 데이터는 각자 브라우저의 localStorage에만 있어 저장소에는 포함되지 않습니다.

## 사용법

- 우측 상단 **"+ 일정 추가"** 버튼으로 일정을 등록합니다. (사건번호, 사건명, 일정유형, 날짜/시간, 법원, 메모)
- 사건 하나에 기일이 여러 개면 "+ 날짜 추가"로 한 번에 여러 날짜/시간을 등록할 수 있습니다.
- "기존 사건에서 선택" 드롭다운으로 이미 입력된 사건번호를 골라 사건번호/사건명/법원을 자동으로 채울 수 있습니다.
- 일정유형은 자유 입력이며 변론기일/선고기일/준비기일/조정기일/서면제출 등을 추천 목록으로 제공합니다.
- 상단 "중요 일정" 목록은 완료되지 않은 일정을 날짜순으로 보여주며, 기한이 지난 항목은 빨간색, 3일 이내 항목은 주황색으로 강조됩니다.
- 각 일정의 체크박스를 누르면 "완료" 처리되어 상단 목록에서 빠집니다. (완료 항목은 "완료된 일정도 보기" 체크로 다시 볼 수 있습니다)
- **캘린더** 탭: 날짜를 클릭하면 해당 날짜의 일정 목록/추가 화면이 열립니다.
- **사건별(의뢰인)** 탭: 같은 사건번호의 일정을 모아서 보여줍니다. 사건번호/사건명으로 검색할 수 있습니다.
